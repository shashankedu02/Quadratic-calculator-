# Quadratic Calculator — Web

A lightweight, dependency-free browser app for solving quadratic equations:

```
ax² + bx + c = 0
```

It validates input, explains whether the equation has two real roots, one repeated root, or complex roots, and shows the calculation clearly.

## Use it

Open `index.html` in any modern browser. No installation or build step is needed.

## Example

For `x² - 5x + 6 = 0`, enter:

- `a = 1`
- `b = -5`
- `c = 6`

The calculator returns `x = 2` and `x = 3`.

## Project files

- `index.html` — page structure
- `styles.css` — responsive interface
- `script.js` — equation-solving logic
